# 扫雷叠加器（KK对战平台 · 2026 双节探宝活动 · 第二关）

把求解器的推断结果半透明地叠在游戏窗口上，实时标注每一格是宝藏还是炸弹，
并推荐下一步挖哪里，支持全自动挖宝。

**适用范围：KK对战平台 2026 年「双节探宝」活动第二关**（18×18 棋盘，
38 宝藏 / 26 炸弹）。其他尺寸的活动关卡把面板里的参数改成对应值即可。

## ⚠ 必须以管理员身份运行

**请右键 exe →「以管理员身份运行」。**

KK对战平台本身以管理员权限运行时，Windows 的 UIPI 机制会拦截普通权限程序
发出的模拟点击——这就是自动挖宝点不动的原因。只有叠加器也以管理员运行，
点击才能被游戏接收。识别和叠加不受此影响，但自动挖掘（F9）必须要管理员。

## 功能

- **实时叠加**：框选棋盘后，在游戏画面上直接叠出每一格的结论：
  - 绿底「宝」= 确定宝藏，红底「弹」= 确定炸弹，深灰 = 确定空地
  - 绿底数字 = 安全格（已证明不可能是炸弹），数字是宝藏概率
  - 深红底数字 = 危险格，数字是炸弹概率
- **推荐下一步（白框）**：零风险格里挑"宝藏概率 + 0.3×连锁概率"最高的，
  一个零风险格都没有才冒险挑炸弹概率最低的；"不可能再有宝藏"的死区一律跳过。
- **F9 自动挖宝**：自动把鼠标移到推荐格，按人手节奏（落点抖动、按下保持
  ~160ms）点击挖开，挖完挪开鼠标等下一格；连续 3 次点了没反应自动停。
- **找齐收工**：38 个宝藏全部挖到后自动停止挖掘、清除框选。
- **悬停保持**：鼠标悬停格子的高亮不会被误认成"已挖开的宝藏"，
  不会带着整盘重算。

## 热键

| 键 | 作用 |
|---|---|
| F11 | 框选棋盘范围（按住左键拖矩形，松开生效） |
| F12 | 取消框选、收起叠加层 |
| F9  | 开/关 自动挖开推荐格 |
| F10 | 存下当前帧 + 识别诊断（排查识别问题时用） |

面板参数：棋盘边长（默认 18）、宝藏总数（38）、炸弹总数（26）、
不透明度、刷新间隔。

## 使用

1. 右键 `扫雷叠加器.exe` → **以管理员身份运行**（单文件，免安装）。
2. 打开活动第二关，让棋盘完整出现在屏幕上。
3. 按 F11 框住棋盘，叠加层立即出现。
4. 自己看着挖，或按 F9 挂机。
5. 首次运行若被 Windows Defender / SmartScreen 拦截：点「更多信息」→
   「仍要运行」。这是未签名 PyInstaller 程序的常见误报（详见
   [使用说明.txt](叠加器exe/使用说明.txt)）。

## 从源码构建

```
python 叠加器exe\构建.py
```

需要 Python 3.14 + PyInstaller，以及 `叠加器exe\node\node.exe`
（识别和求解引擎跑在 Node 上，因体积原因不入库，需自备 node.exe 放到该路径）。

## 目录结构

```
├─ 叠加器\            源码：overlay.py（主程序）/ bridge.js（引擎桥）/
│                     engine_core.js（识别+求解引擎）/ templates.json（字形模板）
├─ 叠加器exe\         构建工程：构建.py / 启动入口.py / 图标 / 版本资源
├─ 扫雷模拟器.html    引擎来源（浏览器里同款求解器，可单独打开玩）
└─ 地图生成器.html
```
